## Which Next.js docs to read

The block above is generated by `next dev` and names the upstream path. **This repo's source is the
`nextjs-docs` skill**, which indexes the copy at `.next-docs/` — the same source the root `AGENTS.md`
names. Use the skill. Its copy is version-matched to whenever the codemod last ran, not to the
installed `next` on its own, so refresh it after a Next.js upgrade.

The two differ in availability. `node_modules/next/dist/docs/` ships inside the `next` package, so it
is there whenever dependencies are installed. `.next-docs/` is gitignored and built per checkout, so a
fresh worktree usually has none — this one included. When the skill reports its docs missing, refresh
it with the command under "Refreshing the index" in the skill itself, which runs from the repo root and
writes the skill file rather than this one. Either way, read a doc rather than falling back to training
data.

leaves it alone.
