## Which Next.js docs to read

The block above is generated by `next dev` and names the upstream path. **This repo's source is the
`nextjs-docs` skill**, which indexes the version-pinned copy at `.next-docs/` — the same source the
root `AGENTS.md` names. Use the skill; it resolves to the version actually installed here.

Neither path is guaranteed to be present: a worktree installed with `--ignore-scripts` has no
`node_modules/next/dist/docs/`, and `.next-docs/` is generated rather than committed. When the skill
reports the docs missing, run `npx @next/codemod agents-md --output AGENTS.md` to regenerate them
rather than falling back to training data.

This section sits outside the generated markers on purpose, so `next dev` rewriting the block above
leaves it alone.
