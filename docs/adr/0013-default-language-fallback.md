# Creatives fall back to the default language, unlike surveys

When a visitor's language is missing, a creative still shows in its default language, while a survey is skipped (ENG-3866). An always-on button vanishing for some visitors is worse than showing it in the default language. The exception is a popup Destination the visitor's language would skip: then the creative is hidden, and the editor warns about it, because a button that opens nothing feels broken.
