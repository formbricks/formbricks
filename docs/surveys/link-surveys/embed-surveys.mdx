A published link survey can be embedded in a web page without redirecting respondents to a separate survey site. The survey keeps its own styling, so it sits inside your page like any other component.

## Embed a survey in a web page

Publish a link survey (ask your agent to create and publish it over [MCP](/platform/mcp/overview)), then paste an iframe that points at its public URL into the HTML of your page:

```html Example embedding code
<div style="position: relative; height:100vh; max-height:100vh; overflow:auto;">
  <iframe
    src="https://app.formbricks.com/s/<your-surveyId>?embed=true"
    frameborder="0"
    style="position: absolute; left:0; top:0; width:100%; height:100%; border:0;"
  >
  </iframe>
</div>
```

Replace `https://app.formbricks.com` with your own domain if you self-host.

### Embed mode

Appending `?embed=true` to the survey URL renders the survey in a minimalist design that disregards padding and background, so it blends into the surrounding page. Leave it off to show the survey on its regular background.

## Iframe events

The iframe posts a `formbricksSurveyCompleted` message to the parent page when a respondent finishes the survey. Listen for it in your page's JavaScript:

```javascript Example event listener
window.addEventListener("message", (event) => {
  // Replace with the origin of your Formbricks instance
  if (event.origin === "https://app.formbricks.com" && event.data === "formbricksSurveyCompleted") {
    console.log("Survey completed!");
    // Implement your custom actions here
  }
});
```

<Note>
  Always verify `event.origin` so that only messages from the iframe that contains your survey trigger your
  code.
</Note>

## Embed a survey in an email

Most email clients block iframes and scripts, so embed a **link** instead. A survey URL can carry an answer for a [hidden field](/surveys/embedded-data/set-embedded-data) or [prefill a question](/surveys/link-surveys/data-prefilling), which lets a respondent answer with one click straight from the email.

```html Example one-click answers in an email footer
Was our conversation helpful?
<a href="<Link-Survey-URL>?helpful=Yes">Yes 👍</a> |
<a href="<Link-Survey-URL>?helpful=No">No 👎</a>
```

Declare `helpful` as a hidden field on the survey (your agent can add it), and replace `<Link-Survey-URL>` with the URL of the published survey. Test the email in the clients your audience uses before you send it.
