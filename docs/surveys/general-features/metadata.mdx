## Metadata Captured

- **Source**: Where the respondent came from. A link survey opened with `?source=` records that value; without one it records the survey's type, `link` or `app`. See [Source Tracking](/surveys/link-surveys/source-tracking).

- **URL**: The URL of the page where the user filled the survey.

- **Browser**: The browser used by the user to fill the survey.

- **OS**: The operating system of the device used by the user to fill the survey.

- **Device**: The device used by the user to fill the survey.

- **Country**: The country of the user.

- **Action**: The action that triggered the survey. This is only available for App surveys.

## View Response Metadata

Open the **Responses** tab of your survey and scroll the table to the right. Each metadata field is a column of its own, so a whole set of responses can be read at once.

![The metadata columns of the responses table](/images/surveys/general-features/metadata/response-metadata.webp)

The gear icon above the table hides columns you do not want to see.

## Filter Responses by Metadata

**Filter**, above the table, offers the same fields. Pick one, choose a condition and a value, and the table narrows to the responses that match — useful for questions like "what did the people who came from the newsletter say?".

## Export Metadata

You can export the metadata of your responses along with the response data. When you export responses, you will see the metadata fields in the exported CSV file.
