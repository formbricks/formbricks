## Recall Sources

You can recall data from the following sources:

- From a previous question

- From a [Hidden Field](/surveys/general-features/hidden-fields)

- From a [Variable](/surveys/general-features/variables)

## Recalling from a previous question

<Note>
  On the first question the menu lists only hidden fields and variables — there is no earlier answer
  to recall yet.
</Note>

### Step 1: Insert the recall

Type **`@`** in the question or description where the value should appear. A menu opens listing everything available at that point in the survey — the questions before this one, the hidden fields, and the variables.

![The recall menu, listing earlier questions, hidden fields and variables](/images/surveys/general-features/recall/recall-menu.webp)

### Step 2: Set a fallback

Pick a source and the editor asks for a fallback: the text to show when there is nothing to recall. An optional question that was skipped, or a hidden field the URL never filled, would otherwise leave a gap in the sentence.

![The fallback prompt that opens after picking a recall source](/images/surveys/general-features/recall/fallback.webp)


## Recalling from the URL

1. Create a hidden field, [here is how →](/surveys/general-features/hidden-fields)

2. Use the `@` symbol in a question or description to recall the value of the hidden field

3. Set a fallback in case the hidden field is not being filled by a URL parameter

4. Use [Data Prefilling](/surveys/link-surveys/data-prefilling) to set the hidden field value when the survey is accessed

## Recalling from a Variable

1. Create a variable, [here is how →](/surveys/general-features/variables)

2. Use the `@` symbol in a question or description to recall the value of the variable

3. Set a fallback in case the variable has not been calculated yet when the question is shown

## **Conclusion**

Recall Data in Formbricks surveys allows for a conversational and customized survey experience that enhances engagement and improves the quality of feedback. By integrating previous responses into new questions, you create a more interactive and relevant environment for respondents.
