including patch releases. This index holds detailed and historical procedures linked from those notes.
Choose your [upgrade path](/self-hosting/upgrade/paths), then use [Upgrading Formbricks](/self-hosting/advanced/upgrade)
for the shared checklist. Each release uses Before / During / After / Recovery; detailed SQL and component
procedures are linked from the checklist.
