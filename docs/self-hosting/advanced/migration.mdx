Each page lists what changes in that version and what you need to do. From 4.0 onward, upgrade one minor
version at a time; the [upgrade paths](/self-hosting/upgrade/paths) table shows your next stop. Then follow the
[standard upgrade](/self-hosting/advanced/upgrade) for your setup.

Patch-level changes are listed on each minor's page under **patch actions**, and in the
[release notes](/platform/changelog). If a migration fails, see [troubleshooting](/self-hosting/upgrade/troubleshooting).
