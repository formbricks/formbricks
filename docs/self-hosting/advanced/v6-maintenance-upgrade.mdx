The v5 → v6 steps are on the [6.0 upgrade guide](/self-hosting/upgrade/versions/6.0). Upgrade from the latest
5.4 patch, then follow the runbook for your setup:
[Kubernetes](/self-hosting/upgrade/kubernetes), [Docker Compose](/self-hosting/upgrade/docker) or
[one-click](/self-hosting/upgrade/one-click).

For later v6 upgrades, start with [Upgrade Formbricks](/self-hosting/advanced/upgrade). If permission
preparation fails, see [preparation results](/self-hosting/upgrade/prepare#results-and-recovery).
