Use this page to choose which Formbricks services to run and prepare your container image allowlist.

## Components

| Component | Required for | External option |
| --- | --- | --- |
| [Formbricks app](https://github.com/formbricks/formbricks) | Always: UI, APIs and application jobs | Run the Formbricks image |
| [Hub API and worker](https://github.com/formbricks/hub) | Always: feedback processing and Hub jobs | Run the Hub image |
| [Cube](https://github.com/formbricks/formbricks/tree/stable/docker/cube-image) | Always: analytics queries | Your own Cube deployment |
| PostgreSQL with [pgvector](https://github.com/pgvector/pgvector) | Always: application and Hub data | [RDS for PostgreSQL](https://docs.aws.amazon.com/AmazonRDS/latest/PostgreSQLReleaseNotes/postgresql-extensions.html) with the `vector` extension |
| Redis/[Valkey](https://github.com/valkey-io/valkey) | Always: jobs, caching and application rate limits | [ElastiCache](https://docs.aws.amazon.com/AmazonElastiCache/latest/dg/Durability.Options.html) with `noeviction` |
| [SpiceDB](https://github.com/authzed/spicedb) | Always in v6: permission checks | An external AuthZed endpoint |
| [SpiceDB operator](https://github.com/authzed/spicedb-operator) | Kubernetes-managed SpiceDB only | An existing compatible operator, or external AuthZed |
| Edge gateway ([Envoy](https://github.com/envoyproxy/gateway) or equivalent) | Public routing and edge rate limiting | A gateway providing [equivalent coverage](/self-hosting/configuration/rate-limiting) |
| S3-compatible storage | File uploads, images and branding | [Amazon S3 or another S3-compatible service](/self-hosting/configuration/file-uploads) |
| [Taxonomy](/self-hosting/configuration/ai-features), [embeddings](https://github.com/huggingface/text-embeddings-inference) and [LLM runtimes](https://github.com/vllm-project/vllm) | Enabled AI features only | Hosted inference endpoints replace model runtimes; taxonomy still needs its service |
| SMTP | Sending email | [An SMTP provider](/self-hosting/configuration/smtp), including Amazon SES |

Self-hosted SpiceDB needs a separate database and role on the application's PostgreSQL server or another server.
Keep it private. See [AuthZed operations](/self-hosting/configuration/authzed-operations).

Envoy supplies gateway routing and edge rate limiting. Helm leaves it disabled by default. A load balancer
or the one-click installer's Traefik proxy alone does not supply the documented edge rate-limit coverage.

## Container images

Repository names are listed below. Use the tags or digests shipped with your Formbricks release and
deployment configuration; migrations and initialization reuse the app or Hub image.

Sources: [Compose](https://github.com/formbricks/formbricks/blob/stable/docker/docker-compose.yml),
[one-click installer](https://github.com/formbricks/formbricks/blob/stable/docker/formbricks.sh), and
[Helm values](https://github.com/formbricks/formbricks/blob/stable/charts/formbricks/values.yaml).

<Info>
  `latest` is a moving tag. Keep the versions selected by your deployment files when mirroring images;
  PostgreSQL major versions and other dependencies must remain compatible with your release.
</Info>

architecture and GPU requirements; model files are downloaded separately.

## Configuration

Follow the [Docker](/self-hosting/setup/docker), [one-click](/self-hosting/setup/one-click) or
[Kubernetes](/self-hosting/setup/kubernetes) guide for setup. Configure optional
[AI services](/self-hosting/configuration/ai-features) and an
[Enterprise license](/self-hosting/advanced/license) before using Enterprise features.
