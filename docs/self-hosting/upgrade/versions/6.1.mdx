## Before

- Applies to self-hosted 6.0 → 6.1 upgrades. From v5, complete the [6.0 prerequisites](/self-hosting/upgrade/versions/6.0) first.
- The [published release notes](/platform/changelog) identify **6.0.2 → 6.1.0** as the tested pair.
  This is reported release evidence, not a runtime rehearsal of your deployment.
- Plan maintenance for respondent traffic, APIs and admin access; pause background workers.
- Read the integration changes below before scheduling the upgrade.

## During

Use [Kubernetes](/self-hosting/upgrade/kubernetes) or [Docker Compose](/self-hosting/upgrade/docker).
This release changes the permission schema. Review its current digest before preparation; do not bypass
the mismatch check. The [online mode](/self-hosting/configuration/online-upgrade) remains under validation.

## After

Verify permissions, respondent submission, a scoped API key, background delivery and dashboard charts.
Regenerate encrypted single-use links after deployment. Enable survey visibility only after its checks pass.
Use [coordinated recovery](/self-hosting/operate/backup-restore) if repair cannot complete.

## Integration changes requiring action

These are historical compatibility exceptions; the [compatibility commitment](/self-hosting/advanced/release-maintenance-policy#integration-compatibility)
does not erase them.

- Regenerate [encrypted single-use links](/self-hosting/upgrade/versions/6.1-single-use-links).
- Review [Helm security contexts and taxonomy timeouts](/self-hosting/upgrade/versions/6.1-runtime#helm-security-contexts-and-taxonomy-timeouts)
  if you use custom images or override taxonomy settings.

**API**

* **Ending-card URLs need a real host.** `buttonLink` and `url` on ending cards (v1, v2 and v3 survey create and update) must use a hostname with a dot (`intranet.example.com`), `localhost` or an IP address. A host like `http://intranet` now returns 400. Existing surveys keep loading; the rule applies when they are next saved ([#9399](https://github.com/formbricks/formbricks/pull/9399))
* **Hidden fields can't share a name with a question.** Adding one on `POST` or `PUT /api/v1/management/surveys` returns 400. Existing surveys keep saving ([#9467](https://github.com/formbricks/formbricks/pull/9467))
* **New survey limit per workspace.** `SURVEY_WORKSPACE_LIMIT` (a number, default `10000`, archived surveys included) caps the surveys in one workspace. Creating or copying a survey past it returns `422 workspace_survey_limit_reached` on v1 and v3. Raise it before upgrading if a workspace is close ([#9412](https://github.com/formbricks/formbricks/pull/9412))
