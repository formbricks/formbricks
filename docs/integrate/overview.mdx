## Choose an API

- **v1:** stable management and client APIs. Use the documented endpoints for supported integrations.
- **v2:** Beta; check endpoint-specific requirements and expect changes during Beta.
- Hub has its own API and deployment. See [Formbricks Hub](/unify-feedback/formbricks-hub).

Keep API keys on the server and grant only the scopes required. [Create a key](/api-reference/generate-key)
and [test it](/api-reference/test-key) before connecting an integration.

## Maintain an SDK integration

Check [feature compatibility](/surveys/website-app-surveys/sdk-compatibility), follow the
[workspace-ID migration](/surveys/website-app-surveys/workspace-id-migration) when applicable,
and use the [framework setup](/surveys/website-app-surveys/framework-guides) for your platform.
