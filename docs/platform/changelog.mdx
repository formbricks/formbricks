Formbricks publishes release notes on [GitHub Releases](https://github.com/formbricks/formbricks/releases).
This page repeats the short summary of each stable release and its **upgrade impact**:

- **Upgrade impact: None.** Follow the [standard upgrade](/self-hosting/advanced/upgrade). Nothing else to do.
- **Upgrade impact: Action required.** Do the linked steps for your setup as part of the upgrade.

To upgrade across several versions, start with [Upgrade paths](/self-hosting/upgrade/paths). Older releases
are on [GitHub Releases](https://github.com/formbricks/formbricks/releases), and their upgrade steps are in
[All versions](/self-hosting/advanced/migration).

<Update label="6.1.0" description="19 October 2026">
<span id="release-6-1-0" />
### Overview

Formbricks 6.1 adds survey visibility, so organizations can restrict who sees each survey and its responses, and brings dark mode and Custom CSS to surveys. It also adds Qualtrics survey import from .qsf files, Embedded Data V2 with a shared field library, the v3 Responses API with matching MCP tools, and new chart types and filters.

Self-hosters: upgrade from the latest 6.0 patch with the [standard upgrade](/self-hosting/advanced/upgrade), in a maintenance window, and follow the [6.1 upgrade guide](/self-hosting/upgrade/versions/6.1).

Formbricks 6.1 receives bug fixes and security fixes until **19 January 2027**.

### ⚠️ Breaking changes

**Upgrade impact: Action required.** 6.1 is a minor release, but some setups need to act:

| Affected deployment | Check before upgrading |
| --- | --- |
| Every self-hosted deployment | Permission preparation in a maintenance window, then the [6.1 checks](/self-hosting/upgrade/versions/6.1) |
| Encrypted single-use links | [Regenerate links](/self-hosting/upgrade/versions/6.1-single-use-links) |
| Custom Helm images or taxonomy overrides | [Security contexts and timeout validation](/self-hosting/upgrade/versions/6.1-runtime#helm-security-contexts-and-taxonomy-timeouts) |
| API integrations | [URL validation, hidden-field names and workspace limits](/self-hosting/upgrade/versions/6.1#integration-changes-requiring-action) |

[All 273 changes on GitHub](https://github.com/formbricks/formbricks/releases/tag/6.1.0)
