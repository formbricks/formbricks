## Welcome to the Formbricks Documentation!

Formbricks is an open-source platform for collecting and analyzing feedback from customers, users, and employees, built to be driven by AI agents. You describe what you want, and your agent builds surveys, reads responses and analyzes feedback through the Formbricks MCP server and the v3 API. Respondents still see ordinary survey pages, embeds and in-app surveys.

Formbricks covers the full experience-management (XM) loop: **Ask** with surveys, **Analyze** with Unify Feedback, and **Act** with Workflows.

This guide covers everything you need to connect an agent, run surveys, and self-host Formbricks. It includes step-by-step instructions, feature explanations, and best practices, plus advanced docs on the SDKs, the APIs and the self-hosted setup.
