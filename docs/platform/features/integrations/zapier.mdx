<Note>
  Nail down your survey first? Any changes in the survey cause additional work in the Zap. It makes sense to first settle on the survey you want to run and then get to setting up Zapier.
</Note>

## Step 1: Check your question codes

Every question has a **question code**, such as `q1` or `nps`, and the `dataByQuestionCode` group of the test data shows your answers under these codes. You can read and change the code in the **Settings** tab of a question, under **Recode**, **before** you activate the survey. Once the survey is active, codes are locked, so the Zap you build on them keeps working.

<Note>
  Question codes start with a lowercase letter and use lowercase letters, digits and `_`. Pick short, readable names such as `nps` or `visit_reason`. Learn more in [Question codes and answer codes](/surveys/analysis/question-codes).
</Note>

<Note>
  The Question ID of a question is generated and cannot be changed. If you need it, choose **Copy question ID** in the question's **⋯** menu.
</Note>

## Step 2: Send a test response

In order to set up Zapier you’ll need a test response. This allows you to select the individual values of each response in your Zap.

![Submit Test Response](/images/platform/features/integrations/zapier/submit-test-response.webp)

## Step 3: Setup your Zap

Go to [zapier.com](https://zapier.com) and create a new Zap. Search for “Formbricks” to get started:

![Add New Zap](/images/platform/features/integrations/zapier/add-new-zap.webp)

Then, choose the event you want to trigger the Zap on:

![Choose Event](/images/platform/features/integrations/zapier/choose-event.webp)

## Step 4: Connect Formbricks with Zapier

Now, you have to connect Zapier with Formbricks via an API Key:

![Connect with Formbricks - 1](/images/platform/features/integrations/zapier/connect-with-formbricks-1.webp)

![Connect with Formbricks - 2](/images/platform/features/integrations/zapier/connect-with-formbricks-2.webp)

Now you need an API key. Please refer to the [API Key Setup](/api-reference/generate-key) page to learn how to create one.

Once you copied it in the newly opened Zapier window, you will be connected:

![Successful Connection](/images/platform/features/integrations/zapier/success-connected.webp)

## Step 5: Select Survey

Next, you can choose from all the surveys you have created in this workspace:

![Select Survey](/images/platform/features/integrations/zapier/select-survey.webp)

## Step 6: Test your trigger

Once you hit “Test” you will see the three most recent submissions for this survey. If you don’t have any submissions in the survey, submit one to continue setting up your Zap:

![Test Submission](/images/platform/features/integrations/zapier/test-submission.webp)

<Note>
  Zapier remembers the sample it showed you. If you set up your Zap before question codes existed, or you added questions since, re-test the trigger to load the new fields, including `dataByQuestionCode`.
</Note>

## Step 7: Set up your Zap

Now you have all the data you need at hand. The next steps depend on what you want to do with it. In this tutorial, we will send submissions to a Slack channel:

![Slack Channel Message](/images/platform/features/integrations/zapier/slack-channel-msg.webp)

In the action itself we can determine the data and layout of the message. Here, we only choose the submission data. You can also refer to the meta data of the submission and the [attributes](/surveys/website-app-surveys/user-identification) of the person who submitted the survey.

![Slack Message](/images/platform/features/integrations/zapier/slack-message.webp)

We now receive a notifcation in our Slack channel whenever a Churn survey is completed:

![Zapier Message](/images/platform/features/integrations/zapier/zapier-message.webp)
